Features

📊 Export Library Analytics (CSV, JSON, Markdown)

Export your complete library analytics from a Chrome side panel that detects what you are viewing and offers a one-click download.

Supported views:

  • Components — full list, variant detail (with property usage analysis), variant file usage, single-component file usage
  • Styles — full list and per-style file usage
  • Variables — variables list, modes list, and per-variable file usage

How it works:

  • Open Library Analytics in Figma, then open the side panel from the toolbar or the modal launcher button
  • The panel shows which library and view you are on, and enables Download when export is available
  • Choose CSV, JSON, or Markdown; inline export buttons also appear in the modal while the panel is open
  • Works from the workspace, inside a design file, or via the Libraries browser

Notes

  • Library analytics requires an Organisation or Enterprise plan
  • The library analytics modal must be open and the Analytics tab selected
  • Detection runs only while the side panel is open

💡 Panel insights

While you browse Library Analytics, the side panel shows usage charts and maintainer notes — top items, zero-instance candidates, variant matrix signals, unused property values, detach rates, and more. Insights load automatically after the table is scanned.

Check Include insights before downloading to append the same analysis to CSV, JSON, or Markdown exports (optional; off by default).

Property usage analysis for variant detail — variant property value counts and percentages — was first added in v1.4.0 by Davy Fung. v1.6.7 expanded this into full panel insights across list and detail views.

📈 Property usage analysis

When exporting variant detail for a component set, the export includes a breakdown of variant property values with instance counts and percentages — available in CSV, JSON, and Markdown. Part of the broader panel insights system since v1.6.7.
